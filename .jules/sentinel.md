## 2024-05-31 - Missing Authorization Checks in Server Actions
**Vulnerability:** Next.js Server Actions (`use server`) exported from `queries.ts` such as `updateUser` and `deleteAgency` lacked authorization checks, leading to Insecure Direct Object References (IDOR) and authorization bypass. An authenticated user could theoretically call these server actions directly to modify arbitrary users or delete an arbitrary agency without possessing the appropriate privileges.
**Learning:** In Next.js, server actions are exposed as API endpoints. Therefore, just because an action is invoked from a restricted client-side UI (e.g. an Admin Dashboard) does not prevent users from executing it directly. The server action must perform its own strict authentication and authorization checks.
**Prevention:** Always use `currentUser()` (or similar context getters) within a server action to verify the invoker's identity, and then assert they have the required roles (like `AGENCY_OWNER`) or ownership for the resource they are acting upon. Do not rely solely on the UI being hidden.
